# Egoist Roulette — Blue Lock Journey

Gerador interativo de uma carreira completa dentro do Blue Lock, inspirado no formato de roletas sequenciais.

## O que a roleta gera

- potencial: gênio, talentoso ou raçudo;
- posição e ego;
- estilo de jogo e arma inicial;
- Primeira Seleção, Segunda Seleção e Blue Lock XI;
- eliminação definitiva, encerrando e bloqueando o restante da jornada;
- clube da Neo Egoist League;
- evolução da arma;
- Meta-Visão, Olhar do Predador ou instinto;
- atributos, overall e status final.

## Rodando localmente

Requer Node.js 22 ou superior.

```bash
npm install
npm run dev
```

Abra o endereço exibido no terminal.

## Build

```bash
npm run build
```

Projeto de fã não oficial. Blue Lock pertence aos seus respectivos autores e detentores de direitos.
